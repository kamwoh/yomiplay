# Yomiplay: rules for AI assistants and contributors

## Copyright and content policy (always applies)

This repository ships **code only**. Never add, generate into, or commit any of the following:

- Game images or files from discs: `.bin .cue .iso .img .chd .pbp .ecm .m3u`, PS1 executables (`SLPS_*`, `SCUS_*`, `SLUS_*`, `SCES_*`, `SLES_*`, `SCPS_*`), and anything extracted from a disc (`.PAC`, `.STR`, `.XA`, `.TIM`, `.VAG`, decompressed archives).
- BIOS files (e.g. `scph*.bin`) and emulator cores (`.so`, `.dll`, `.dylib`).
- Save data: save states, memory cards (`.state .srm .mcr .mcd .mc .gme .vmp`).
- **Game text**: any line of dialogue, menu text or script from a real game, in any language, including translations. Use invented example text in docs, prompts, tests and mockups.
- **Game graphics**: screenshots, sprites, fonts or logos taken from a real game. Use synthetic test images (generated by code) or our own drawings. Exception: a few README screenshots in `assets/screenshots/` that show the app in use (see Allowed).
- Links to ROM or BIOS download sites, or scripts that download them.

Allowed: our own logo and artwork in `assets/brand/`. README screenshots in `assets/screenshots/` that show this app running a game, kept few and small (each under 1 MB). Naming a game as a factual reference ("tested on <title> (<serial>)"), and per-game profiles that hold only our own measurements and hints. Profiles live outside the repository in `~/.config/yomiplay/games/<serial>.toml`; `games/` and `docs/` are gitignored (screen rectangles, RAM addresses, short hints written by us).

Trademarks (game titles, PlayStation, publisher names) must never be used as this project's name, logo or branding.

If a task seems to need any blocked content (for example a real screenshot for a test), stop and ask instead. Users supply their own legally obtained games, BIOS and cores via local config outside the repository.

## Enforcement

`.githooks/pre-commit` blocks commits containing these file types, large binaries, images outside allowed folders, and extracted-script formats. Enable it once per clone:

    git config core.hooksPath .githooks

Do not bypass it with `--no-verify`.
